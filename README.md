# 뷰파인더

사진이 예쁘게 나오는 출사지를 찾고, 현장 정보를 공유하는 iOS 앱입니다.

## 프로젝트 열기

- Xcode 프로젝트: `Viewfinder.xcodeproj`
- 앱 소스 폴더: `Viewfinder`
- 앱 표시 이름: `뷰파인더`
- 타깃/스킴 이름: `Viewfinder`

## 주요 기능

- 현재 위치 기반 출사지 추천
- 네이버 지도 기반 출사지 마커
- 홈 추천 피드와 지역/키워드 검색
- 실시간 현장 정보 작성/수정/삭제
- 저장한 출사지 관리
- Firebase Apple/Google 로그인

예전 테스트 프로젝트들은 루트에서 보이지 않도록 숨김 보관 폴더로 옮겨두었습니다.
